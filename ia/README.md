# TerraNova

## Sobre o Projeto

TerraNova é uma plataforma inteligente desenvolvida para auxiliar produtores rurais na tomada de decisões relacionadas à produtividade agrícola, irrigação e sustentabilidade no campo.

A plataforma combina modelos de Machine Learning, dados climáticos e Inteligência Artificial Generativa para fornecer análises, previsões e recomendações que ajudam a otimizar a produção agrícola e reduzir o desperdício de recursos.

O objetivo do projeto é transformar dados complexos em informações acessíveis e úteis, permitindo que o usuário compreenda melhor as condições da sua produção e tome decisões mais eficientes.

---

## Inteligência Artificial no Projeto

A solução utiliza dois modelos de Machine Learning especializados e um assistente virtual inteligente chamado **GAIA**.

### Modelo 1 – Previsão de Produtividade Agrícola

Este modelo foi treinado para estimar a produtividade de uma cultura com base em fatores como:

* Tipo de solo
* Tipo de cultura
* Temperatura
* Umidade
* Precipitação
* Irrigação
* Região

A partir dessas informações, o modelo realiza uma previsão da produtividade esperada e classifica o resultado em níveis de desempenho.

---

### Modelo 2 – Recomendação de Irrigação

Este modelo tem como objetivo analisar o consumo de água na produção agrícola.

Para isso, utiliza informações como:

* Tipo de cultura
* Umidade do solo
* Estágio de crescimento
* Área plantada
* Método de irrigação
* Condições climáticas

Com base nesses dados, o sistema gera recomendações para auxiliar no uso eficiente da água, contribuindo para a redução de desperdícios e para uma irrigação mais sustentável.

---

### GAIA – Assistente Virtual Inteligente

GAIA é a assistente virtual da plataforma TerraNova.

Sua função é interpretar os dados gerados pelos modelos de Machine Learning e responder dúvidas dos usuários relacionadas ao contexto agrícola.

O assistente é especializado em:

* Agricultura
* Irrigação
* Clima
* Consumo de água
* Sustentabilidade agrícola
* Produtividade agrícola
* Monitoramento ambiental

Além de responder perguntas, a IA é capaz de transformar resultados técnicos em explicações simples e acessíveis, facilitando a compreensão das análises realizadas pela plataforma.

---

## Integração com Dados Climáticos

Para complementar as análises, o sistema utiliza informações climáticas obtidas através da NASA POWER API.

Entre os dados utilizados estão:

* Temperatura
* Umidade
* Precipitação
* Velocidade do vento
* Radiação solar

Essas informações auxiliam os modelos de Machine Learning a produzir previsões mais próximas das condições reais da lavoura.

---

## Objetivo Final

O principal objetivo do TerraNova é fornecer uma ferramenta inteligente de apoio à decisão agrícola, capaz de unir análise de dados, Machine Learning e Inteligência Artificial para melhorar a produtividade, promover o uso consciente da água e contribuir para uma agricultura mais eficiente e sustentável.
